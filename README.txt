MY BIBLE DICTIONARY PHONE APP

This is an installable Progressive Web App (PWA).

To put it on a phone:
1. Upload all files in this folder to the same HTTPS website folder.
2. Open index.html through that website address on your phone.
3. iPhone/iPad: Safari > Share > Add to Home Screen.
4. Android: Chrome or Edge > menu > Install app or Add to Home screen.

Entries are stored in that browser on that device. Use Backup > Export backup regularly.
The KJV is the default version. Other version names are provided for organizing comparison notes; copyrighted Bible text is not bundled.

SEARCH HISTORY
The app saves up to 25 recent searches on the device. Tap a recent search to run it again, remove individual searches, or clear all history.

ENTRY NOTES
Use the Notes button on any dictionary entry to keep multiple dated study notes. Notes can be edited or deleted and are included in JSON backups.

FAVORITES AND COMPLETE KJV
Favorite dictionary entries and bookmark verses. The Bible reader provides all 66 KJV books and loads chapters from the public-domain KJV dataset when online.

BIBLE VERSION MENU
The reader defaults to KJV and includes a dropdown for ASV, Douay-Rheims American, and Darby. Chapter text requires an internet connection.

COMPARE VERSIONS
Choose a primary Bible version and a second version. On larger screens they appear side by side; on phones they stack for easy reading.

NIGHT MODE
Tap the Night/Day button in the app header. The app remembers the selected theme on the device.

PRAYER AND DAILY VERSE
Includes an editable prayer list, answered status, topical prayer scripture references, and daily verse reminders. Browser/phone support controls whether notifications can arrive while the app is closed.

SCRIPTURE MEMORY AND PRAYER FOLLOW-UP
Adds Scripture memory practice, contact details, request and follow-up dates, follow-up notes, and praise reports. Prayer and memory data are included in app backups.

THE FILLING STATION
A personal Bible study area for sermons, personal studies, Sunday school, conferences, devotionals, book studies, and other teaching. Records topic, Scripture references, speaker or teacher, date, location, notes, application, questions, and prayer response.

FILLING STATION NOTE SYMBOLS
The first section explains NTS, QTS, CTS, and STLS. Tap a symbol to insert it into the currently selected study note field.

NOTE TAG SYSTEM
Add comma-separated tags to Filling Station notes, use quick-tag buttons, search by tag, and filter all studies by a selected tag. Existing studies continue to work without tags.

PRINTABLE REPORTS
The Prayer List can print all, due/overdue, upcoming, or answered/praise follow-ups. The Filling Station can print all Bible study notes or only the currently displayed filtered studies. Use the phone print dialog to print or save as PDF.

FUEL BRANDING AND GOOGLE DOCS EXPORT
The app is renamed Fuel and includes a custom faith-and-fuel logo. Export to Google Docs creates a compatible Word/HTML document and opens Google Docs for upload.

DEFAULT STUDY BIBLE
Fuel now identifies The Open Bible, KJV as the default study Bible and labels study-reference fields accordingly. Fuel uses KJV Scripture text. The proprietary Open Bible study notes, topical index, and cross-reference system are not bundled; an official resource link is included.

GOOGLE DRIVE BACKUP
Back up to Google Drive creates a complete dated JSON backup. On phones that support file sharing, select Google Drive in the device share sheet. Otherwise Fuel downloads the backup and opens My Drive so the file can be uploaded.
